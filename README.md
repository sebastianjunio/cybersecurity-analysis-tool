### Cybersecurity Analysis Tool

## Project Overview

This project is a basic cybersecurity analysis tool designed to assist with security monitoring and log analysis.

## Objectives

Identify failed login attempts from security logs.

Demonstrate version control using GitHub.

Track and resolve development issues using Freshworks.
